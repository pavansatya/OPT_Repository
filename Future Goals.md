I have decided to turn my Capstone Project into a full-fledged web application using all the open-source data from the *Open Food Facts* organisation. 

**Why**: So far, we have been able to use only 1 GB of data, i.e. a small bite from the big pie (the original dataset was nearly 50 GB). So, just imagine if we can leverage all the big data knowledge that we gain and build something useful to society and make it a non-profit and free to use.

**Types of Data sources**: We have several data sources available in the *Open Food Facts*, such as Parquet, JSON, APIs and even flat files like CSV. So, we must choose which mode is easier for us and cost-efficient.
